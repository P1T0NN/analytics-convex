# 1.0.1 roadmap

Post-1.0 follow-up: dashboard query features plus operational infra.

Use **bun** for all local commands.

---

## Dashboard query features (1.0.1)

| Feature | Status | Notes |
| --- | --- | --- |
| Week / month query buckets | 🚧 | Query-time re-aggregation from daily/hourly rollups |
| Funnel / journey breakdown by dimension | 🚧 | Ecom-style conversion by plan, region, etc. |
| Timezone-aware calendar days (query v1) | ✓ | Optional `timezone` on reads; UTC writes unchanged — **verify Intl on Convex dev before 1.0.0** (see `1.0-roadmap.md`) |
