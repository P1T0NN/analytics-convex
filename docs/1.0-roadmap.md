### Manual: Convex runtime timezone check (before 1.0.0)

Local tests (`convex-test` / edge runtime) ship full ICU. **Convex production V8 may not**
support `Intl.DateTimeFormat` with IANA zones the same way.

- [ ] Deploy the example app (or your dev project) to a **Convex dev** deployment
- [ ] Call any read that passes `timezone: "America/New_York"` (e.g. `fetchTimeSeries` or `fetchMetricComparison`)
- [ ] Confirm the query succeeds and bucket boundaries look sane (not UTC fallback / throw)

If `Intl` is missing or IANA names fail in dev:

- [ ] Add a lookup-table or fixed-offset fallback for query-time bucketing
- [ ] Document supported timezone mode in `docs/querying.md`

One manual check on dev is enough; do not ship 1.0.0 with timezone docs claiming IANA support until this passes.
